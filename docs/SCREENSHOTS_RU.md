# Скриншоты для отчёта

PDF содержит визуализированные фрагменты фактических журналов. Для буквального
выполнения требования Screenshots дополните сдачу снимками вашего экрана.
Захват интерфейса в текущей сессии автоматизации недоступен.

Сделайте снимки Win+Shift+S и сохраните в output/screenshots:

1. linux.png — терминал Linux, путь, поиск и права 600/644.
2. git.png — `git log --oneline --graph --all` и ветки.
3. github.png — https://github.com/asylbektajibayev-max/tajibayev-assylbek-devops.
4. docker.png — `docker ps` и приложение http://localhost:8086.
5. jenkins.png — Job, успешная сборка и таблица стадий на http://localhost:8096.
6. console.png — Console Output с Git SHA и Finished: SUCCESS.

Не включайте пароль, токен или infra/.env в снимки. Скриншоты можно приложить к
отчёту отдельным приложением или вставить в PDF обычным PDF-редактором.

Видеодемонстрация должна оставаться одной непрерывной записью с вашим голосом.
